# ペーパースケッチ（Paper Sketch）

<p align="center"><a href="README.md">English</a> · <b>日本語</b></p>

Windows のデスクトップの端に置く作業台 **[Hub](https://github.com/satosugarforwork44x-lang/desktop-hub)** の拡張アプリです。
便箋・弔辞・作文帳・感想文・文庫本などの「紙」を選んで、**縦書きでも横書きでも**文章を書き、そのまま印刷・PDF にできます。
ルビ・揃え・太字・斜体・行間・字間は Word と同じ感覚で使え、**絵・図形・文字ボックス**も紙の上に置けます。
小説を書く人向けに、**作品ごとの用語集**（登場人物・地名・独自の読み）があり、ルビを「毎回」「章の初出だけ」付けられます。校正は AI（Claude・ChatGPT・Gemini）に頼めます。

![ペーパースケッチ — 縦書きの便箋。上が紙のプレビュー、下が打ち込み欄、右が設定](docs/paper-sketch.ja.png)

## 作った理由

手紙・お礼状・子どもの作文・弔辞。どれも「紙の形」が決まっているのに、Word で作ると思いのほか手間がかかります。

- **縦書きの原稿用紙が作りにくい。** マス目と字をそろえるだけで一仕事です
- **ルビの付け方がわかりにくい。** 子ども向けの文章ではよく使うのに、メニューの奥にあります
- **文章そのものは、ほかのアプリや AI と行き来したい。** iPhone のメモで下書きして、AI に校正してもらって、紙に印刷する

そこでペーパースケッチは、**紙を選ぶ → 書く → 印刷する** だけにしぼりました。

- **紙は 12 種類から選ぶだけ。** 判型・縦横・罫線・マス目・余白・色はひな形に入っていて、あとから変えられます
- **打ち込み欄はいつも横書き。** 書きやすい横書きで打ち、上の紙（縦書き）がすぐ変わります
- **本文は 1 つのテキスト。** 書式は `**太字**`・`｜漢字《かんじ》` のような短い記号で持つので、AI に渡しても崩れません

![紙を選んでから、印刷・PDF まで](docs/flow.ja.png)

## UX で決めたこと

| 決めたこと | 理由 |
|---|---|
| **上に紙、下に打ち込み欄、設定は右** | 縦書きの紙の上で直接打つと、カーソルの動きが分かりにくくなります。横書きで打って、結果を紙で見る形にしました。紙・文字・題名・挿入・用語集の設定は右のタブにまとめ（見出しのボタンでしまえます）、紙と打ち込み欄を広く使います |
| **組版は自前で、1 字ずつ位置を決める** | ブラウザの折り返しに任せず、字数×行数・マス目に合わせて置きます。プレビュー・印刷・PDF がまったく同じになります |
| **書式は 3 つの単位** | 文書全体（書体・大きさ・行間・字間）/ 段落（揃え）/ 文字（太字・斜体・ルビ）。段落の途中で書体を変える機能は入れません（保存の形が Word 並みに複雑になるため） |
| **縦書きでは「左揃え」が「天付き」** | 揃えのボタンの絵と名前が、縦書き・横書きで切り替わります。署名の地付きにそのまま使えます |
| **縦書きでは斜体を使えない** | 日本語の書体には斜体がなく、縦書きで傾けると崩れるため。データは残るので、横書きに戻すと出ます |
| **禁則は日本語の組版のきまり** | 「、。」は行末にぶら下げ、行頭に来てはいけない字（」ー っ など）は前の字と一緒に送ります |
| **書き出した txt は、読み込むと元どおり** | txt の 1 行目に紙の設定を入れます。本文だけが欲しいとき（iPhone のメモ・ほかのアプリ）は「本文だけを txt に」を使います |
| **絵・図形は「紙の上に置く物」** | 本文の流れとは別に、紙の上の位置（mm）で持ちます。本文を直しても絵がずれず、印刷でも同じ場所に出ます。文字の回り込みはしません（「文字の後ろ」にすると地紋や飾りになります） |
| **絵はハッシュの名前で 1 か所に** | 取り込んだ絵は `Paper Sketch\_images` に中身のハッシュの名前で写します。同じ絵は 1 つだけで、書き出した文書を読み込んでも同じ絵を指します |
| **用語集は作品ごと、ルビは組版で付ける** | 小説は章ごとに文書を分けることが多いので、用語集は作品に 1 つ（`<作品名>.dict.json`）にし、章どうしで共有します。本文には「東雲」とだけ書き、ルビは組版が付けます。読みを直すと全部の章が変わります |
| **「ふつうの読み」は自動で判定しない** | 読みの辞書（形態素解析）を入れると重くなるため、登録するときに「毎回」「初出だけ」を選びます。独自の読みを選ぶと「毎回」が既定になります |
| **版は丸ごと残し、違いを見てから戻す** | 書いている間は 10 分ごと、開いた時、AI に渡した時・AI で直す前後、Claude が外で書き換える前後、戻す前に自動で残します。「今と比べる」「1 つ前の版と比べる」で、直した字だけが色で分かります。戻す前の文書も版に残るので、戻したことも戻せます |
| **上書きしない** | 書き出しは `名前 (2).txt`。編集はその場で保存し、外で（Claude が）書き換えても Ctrl+Z で戻せます |

## 紙のひな形

![紙を選ぶ画面](docs/papers.ja.png)

| 種類 | ひな形 |
|---|---|
| メモ・原稿 | 罫線メモ（A5 横書き）、小説（A4 横・縦書き 40字×30行） |
| 手紙 | 便箋（A5、縦書き／横書き、台紙の色を選べる）、弔辞（奉書紙風、A4 横・縦書き） |
| 学校 | 絵日記（絵の枠＋マス目）、作文帳 120字（12×10、十字の補助線）・162字（18×9）・200字（20×10）、感想文（A4 の 400字詰め） |
| 本 | 文庫本 A6（縦書き 38字×16行 ＝ 1 ページ 約600字）、A5 学術書・教科書（横書き 36×28）、A5 文芸誌・総合誌（縦書き 2 段組） |

どのひな形も、判型（A4・B5・A5・A6）・縦長／横長・縦書き／横書き・罫（なし・罫線・マス目）・余白・段組・ページ番号を変えられます。

| 機能 | 内容 |
|---|---|
| **書体** | PC に入っている書体だけを出します（游明朝・游ゴシック・BIZ UD・UD デジタル教科書体・HG正楷書体 など） |
| **大きさ・行間・字間** | pt・倍・em で指定。または「字数×行数」を決めて、大きさを自動で合わせる |
| **揃え** | 左（天付き）・中央・右（地付き）・両端揃え・均等割り付け。`Ctrl+L / E / R / J`、均等割り付けは `Ctrl+Shift+J` |
| **太字・斜体** | `Ctrl+B` / `Ctrl+I`（斜体は横書きのみ） |
| **ルビ** | 字を選んで「ルビ」ボタン。付いたルビはクリックで直す・外す。紙に出すかどうかを切り替えられる |
| **題名・日付・署名** | 紙の種類に合わせて置きます（手紙は本文の後に日付と署名、作文は 1 行目に題名・2 行目に名前）。「今日」で、縦書きは「令和八年十月十四日」、横書きは「2026年10月14日」 |
| **絵** | 「挿入」の絵のボタン、貼り付け（`Ctrl+V`）、PC からドロップ。PNG・JPEG・GIF・WebP・BMP。角のつまみで大きさ（縦横比はそのまま。`Shift` で自由）・不透明度・角度・文字の後ろ |
| **図形・文字ボックス** | 四角・角丸・丸・線・矢印。線の色と太さ・塗り。図形の中に文字（太字・ルビも）を入れられ、大きさ・色・縦書き・揃えを選べる |
| **置いた物の操作** | クリックで選ぶ・ドラッグで動かす・矢印キーで 1mm（`Shift` で 5mm）・`Ctrl+D` で複製・`Delete` で消す・前へ／後ろへ。どれも `Ctrl+Z` で戻せる |
| **作品の用語集** | 用語集の欄で作品を選ぶ（作る）。人名・地名・用語・独自の読みを登録し、ルビは「毎回」「初出だけ（章ごと）」「付けない」から選ぶ。本文で字を選んで右クリック →「用語集に入れる」。クリックでカーソルの位置に入れる。章に出てくる回数も見える |
| **版（作品の保護）** | 見出しの時計のボタン。版に名前を付けて残す（初稿・送る前など）、違いを比べる、戻す、消す。手で残した版は自動では消えません |
| **長いルビ** | ルビが親文字より長いときは、親文字の間を広げます（1 字に長い読みでも、隣の字にかかりません。マス目では広げません） |
| **打ちながらルビ** | 打ち込み欄で `｜漢字《かんじ》` や `漢字《かんじ》` と打つと、その場でルビになります |
| **台紙の色** | 白・生成り・薄桃・薄黄・古紙・薄緑・薄青・薄紫・薄鼠・朱の罫・奉書紙風。ほかの色も自由に選べます |
| **同じルビは2回目から外す** | 本文に手で書いたルビも、同じ字・同じ読みなら 2 回目から出さない |
| **印刷・PDF** | `Ctrl+P`。プリンターで「Microsoft Print to PDF」を選ぶと PDF |
| **読み込み** | `.txt`（UTF-8・Shift_JIS）・`.paper.json` をパネルに落とす |
| **書き出し** | txt（読み込むと元どおり）・本文だけの txt（ルビは「漢字（かんじ）」）・`.paper.json` |

| **日本語と英語** | パネルはどちらの言語でも使えます |

## 使い始める

**Hub 0.8 以上**が必要です。必須の Python パッケージはありません（画面は HTML、保存は標準ライブラリ）。

1. このリポジトリを、Hub のモジュールのフォルダに **`paper` という名前で**置きます（フォルダ名はモジュールの id と同じにする）
   ```bat
   git clone https://github.com/satosugarforwork44x-lang/paper-sketch "%LOCALAPPDATA%\Hub\modules\paper"
   ```
2. Hub を再起動すると、バーに **ペーパースケッチ** が出ます。紙を選んで書き始めてください。
   文書はフォルダ窓の置き場所の下の **`Paper Sketch`** フォルダにしまうので、そのままフォルダ窓にもなります
3. （任意）Claude に校正してもらうとき: Hub の設定（⚙）→ Claude との連携 → `Paper Sketch` を **読み書き** に。
   Claude は保存先の `PAPER_FORMAT.md` を読んで、書式の記号を残したまま本文を直します

|---|---|---|---|
| `Ctrl+B` / `Ctrl+I` | 太字 / 斜体 | `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+L` / `Ctrl+E` / `Ctrl+R` | 左（天付き）/ 中央 / 右（地付き） | `Ctrl+S` | すぐ保存 |
| `Ctrl+J` / `Ctrl+Shift+J` | 両端揃え / 均等割り付け | `Ctrl+P` | 印刷・PDF |
| `｜漢字《かんじ》` と打つ | ルビ | `Ctrl` + ホイール | プレビューの拡大縮小 |
| `Delete` | 選んだ絵・図形を消す | 矢印キー | 選んだ物を 1mm ずつ動かす（Shift で 5mm） |
| `Ctrl+D` | 選んだ物を複製 | 本文で右クリック | 用語集に入れる・ルビを付ける |

## AI と使う

**ChatGPT・Gemini（校正）:** **AI で校正** →「校正を頼む文をコピー」でチャットに貼り、返ってきた文章を「直った文章を貼って置き換える」に貼ります。
頼む文には作品の用語集を添えるので、独自の読みを誤りとして直されません。置き換える前と後は版に残るので、**版**の窓で直した字を確かめ、気に入らなければ戻せます。

**Claude（Hub の MCP をつないだ Claude Desktop）:** たとえば次のように頼めます。

- 「ペーパースケッチの `第一章` を校正して。書式の記号はそのままで」
- 「`夜明けの街` の章を全部読んで、登場人物と地名を用語集にして」
- 「このお礼状を縦書きの便箋にして、日付を今日にして」

Claude は [`PAPER_FORMAT.md`](PAPER_FORMAT.md)（保存先に自動で置かれる）・`.paper.json`・`.dict.json` を読み、JSON を書き換えます。
パネルは 2 秒ほどで変更を読み直します。書き換えられる前の文書は版に残るので、いつでも戻せます。

![小説の章と作品の用語集。蒼月町・東雲は章の初出だけ、本気（マジ）は毎回ルビが付く](docs/terms.ja.png)

![版の窓。外で書き換えられた後を 1 つ前の版と比べると、直した字だけが色で分かる](docs/versions.ja.png)

## 文書の形

`<名前>.paper.json` は、紙の設定・本文（記号つきのテキスト）・紙の上に置いた物だけの短い JSON です。詳しくは [PAPER_FORMAT.md](PAPER_FORMAT.md)。

```text
　拝啓　秋も深まり、｜紅葉《もみじ》の美しい季節になりました。
　先日は**ありがとうございました**。
>>敬具
```

| 記号 | 意味 |
|---|---|
| 行頭の `>>` `><` `<>` `==` | 右揃え（地付き）・中央・均等割り付け・両端揃え |
| `**…**` `*…*` | 太字・斜体 |
| `｜親文字《ルビ》` `漢字《かんじ》` | ルビ |

## しくみ

| ファイル | 役割 |
|---|---|
| `manifest.json` | Hub のモジュールの定義（`moduleApi 1`、Hub 0.8 以上）。パネル・公開する関数・絵を渡す `/blob/paper/…`・貼り付けた絵を受け取る `upload` |
| `api.py` | 作る・開く・確かめる（読めない所は警告を出して直す）・壊れないように保存・読み込み・書き出し（上書きしない）・作品の用語集・版。Python 標準ライブラリだけ |
| `templates.json` | 紙のひな形・判型・色 |
| `ui/layout.js` | 組版（行の分け方・禁則・揃え・ページ分け）。DOM を使わないので node でテストできる |
| `ui/render.js` | 組んだページを mm 単位の DOM にする（プレビューと印刷で共通） |
| `ui/markup.js` | 本文の記号の読み書き |
| `ui/editor.js` | 打ち込み欄（書式付き）と本文の行き来 |
| `ui/versions.js` / `ui/diff.js` | 版の窓（一覧・比べる・戻す）と、段落ごと・字ごとの違い |
| `ui/terms.js` | 作品の用語集の一覧・登録・クリックで入れる |
| `ui/objects.js` | 絵・図形・文字ボックスを選ぶ・動かす・大きさを変える・設定する |
| `ui/panel.js` | 画面 |
| `PAPER_FORMAT.md` | Claude 向けに書いた形式の説明（保存先に自動で置かれる） |

- **データが正。** `.paper.json` だけが正しい状態です。パネルは更新時刻を見ているので、Claude が直した内容はそのまま画面に出ます（直す前の文書は版に残ります）
- **組版は 1 つの関数。** `layout.js` が文書を「ページ・行・字の位置（mm）」にし、`render.js` が DOM にします。プレビューも印刷も PDF も同じ結果です
- **軽さを優先。** 依存するパッケージはありません。形態素解析の辞書を入れず、ルビの付け方は用語集で人が決めます
